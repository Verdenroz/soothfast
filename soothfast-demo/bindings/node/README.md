# soothfast-stats-native

Robust summary statistics and the FNV-1a fingerprint soothfast gates on

Node.js bindings for the `soothfast_demo` crate, generated by [soothfast](https://github.com/Verdenroz/soothfast). Do not edit by hand: run `cargo soothfast bind gen` instead.

## Install

```bash
npm install soothfast-stats-native
```

## Use

```js
const { Metric, Summary, fingerprint } = require("soothfast-stats-native");
```

## Classes

### `Metric`

Which statistic a comparison reads.


### `Summary`

A robust summary of one sample set.

- `deviations`
- `deviationsAll`
- `deviationsInto`
- `get`
- `label`
- `rescale`
- `parse`
