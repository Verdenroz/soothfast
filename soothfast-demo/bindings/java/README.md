# io.soothfast.stats

Robust summary statistics and the FNV-1a fingerprint soothfast gates on

Java bindings for the `soothfast_demo` crate, generated by [soothfast](https://github.com/Verdenroz/soothfast). Do not edit by hand: run `cargo soothfast bind gen` instead.

## Build

```bash
cargo build --release
```

That writes `target/release/libio_soothfast_stats.so` (`.dylib` on macOS, `io_soothfast_stats.dll` on Windows). Compile the Java sources against it and put the library on the loader's path:

```bash
javac -d out $(find src/main/java -name '*.java')
jar --create --file io_soothfast_stats.jar -C out .
java -Djava.library.path=target/release -cp io_soothfast_stats.jar YourMain
```

## Use

```java
import io.soothfast.stats.Stats;
```

Every handle class implements `AutoCloseable`; call `close()` (or use try-with-resources) to free it deterministically. A `java.lang.ref.Cleaner` frees one you forgot, but not on any schedule you should rely on.

A borrowed buffer parameter (`double[]`, `byte[]`, ...) is read through `GetPrimitiveArrayCritical`: it crosses without a copy, but the garbage collector cannot run for the length of that one call.
