# soothfast-stats-js

Robust summary statistics and the FNV-1a fingerprint soothfast gates on

JavaScript bindings for the `soothfast_demo` crate, generated by [soothfast](https://github.com/Verdenroz/soothfast). Do not edit by hand: run `cargo soothfast bind gen` instead.

## Use

```js
import init, { Metric, Summary, fingerprint } from "./pkg/soothfast-stats-js.js";

await init();
```

## Classes

### `Metric`

Which statistic a comparison reads.


### `Summary`

A robust summary of one sample set.

- `deviations`
- `deviationsAll`
- `deviationsInto`
- `get`
- `label`
- `rescale`
- `parse`
