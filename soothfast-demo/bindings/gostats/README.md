# gostats

Robust summary statistics and the FNV-1a fingerprint soothfast gates on

C bindings for the `soothfast_demo` crate, generated by [soothfast](https://github.com/Verdenroz/soothfast). Do not edit by hand: run `cargo soothfast bind gen` instead.

## Build

```bash
cargo build --release
```

That writes `target/release/libgostats.so` (`.dylib` on macOS, `.dll` on Windows) and `target/release/libgostats.a`. The header is `gostats.h`.

## Use

```c
#include "gostats.h"
```

## Ownership

Anything this library returns by pointer is yours to release:

- a handle, with its `*_free`
- a sequence, with its `*_array_free`
- a string, with `gostats_string_free`

A call that can fail takes a trailing `char **error`. On failure it writes a message there and returns a zero value you must not read; on success it writes `NULL`. Passing `NULL` for `error` discards the message. Every message is a string you release the same way.

## Types

### `gostats_metric`

Which statistic a comparison reads.


### `gostats_summary`

A robust summary of one sample set.

- `gostats_summary_deviations`

- `gostats_summary_deviations_into`

## Go

This package also ships a Go wrapper (`go.mod`, `gostats.go`) generated over the same header and library. Build the library first, then `go build`/`go test` against it with `CGO_ENABLED=1`.

The `-Wl,-rpath` link flag is untested on Windows.
