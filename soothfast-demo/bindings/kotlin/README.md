# io.soothfast.statskt

Robust summary statistics and the FNV-1a fingerprint soothfast gates on

Kotlin bindings for the `soothfast_demo` crate, generated by [soothfast](https://github.com/Verdenroz/soothfast). Do not edit by hand: run `cargo soothfast bind gen` instead.

## Build

```bash
cargo build --release
```

That writes `target/release/libio_soothfast_statskt.so` (`.dylib` on macOS, `io_soothfast_statskt.dll` on Windows). Compile the Kotlin sources against it and put the library on the loader's path:

```bash
kotlinc -d out $(find src/main/kotlin -name '*.kt')
jar --create --file io_soothfast_statskt.jar -C out .
java -Djava.library.path=target/release -cp io_soothfast_statskt.jar YourMainKt
```

## Use

```kotlin
import io.soothfast.statskt.Statskt
```

Every handle class implements `AutoCloseable`; call `close()` (or use Kotlin's `use { }`) to free it deterministically. A `java.lang.ref.Cleaner` frees one you forgot, but not on any schedule you should rely on.

A borrowed buffer parameter (`DoubleArray`, `ByteArray`, ...) is read through `GetPrimitiveArrayCritical`: it crosses without a copy, but the garbage collector cannot run for the length of that one call.
