# soothfast-stats-c

Robust summary statistics and the FNV-1a fingerprint soothfast gates on

C bindings for the `soothfast_demo` crate, generated by [soothfast](https://github.com/Verdenroz/soothfast). Do not edit by hand: run `cargo soothfast bind gen` instead.

## Build

```bash
cargo build --release
```

That writes `target/release/libsoothfast_stats_c.so` (`.dylib` on macOS, `.dll` on Windows) and `target/release/libsoothfast_stats_c.a`. The header is `soothfast_stats_c.h`.

## Use

```c
#include "soothfast_stats_c.h"
```

## Ownership

Anything this library returns by pointer is yours to release:

- a handle, with its `*_free`
- a sequence, with its `*_array_free`
- a string, with `soothfast_stats_c_string_free`

A call that can fail takes a trailing `char **error`. On failure it writes a message there and returns a zero value you must not read; on success it writes `NULL`. Passing `NULL` for `error` discards the message. Every message is a string you release the same way.
