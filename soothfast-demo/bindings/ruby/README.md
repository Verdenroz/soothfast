# soothfast_stats

Robust summary statistics and the FNV-1a fingerprint soothfast gates on

Ruby bindings for the `soothfast_demo` crate, generated by [soothfast](https://github.com/Verdenroz/soothfast). Do not edit by hand: run `cargo soothfast bind gen` instead.

## Install

```ruby
gem "soothfast_stats"
```

## Use

```ruby
require "soothfast_stats"
```

## Classes

### `SoothfastStats::Summary`

A robust summary of one sample set.

- `deviations`
- `deviations_all`
- `deviations_into`
- `get`
- `label`
- `rescale`
- `parse`

## Symbols

- `Metric`: one of :median, :mad, :min, :max

## `SoothfastStats`

- `fingerprint`
