# soothfast-stats

Robust summary statistics and the FNV-1a fingerprint soothfast gates on

Python bindings for the `soothfast_demo` crate, generated by [soothfast](https://github.com/Verdenroz/soothfast). Do not edit by hand: run `cargo soothfast bind gen` instead.

## Install

```bash
pip install soothfast-stats
```

## Use

```python
import soothfast_stats
```

## Classes

### `Metric`

Which statistic a comparison reads.


### `Summary`

A robust summary of one sample set.
