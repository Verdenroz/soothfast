Measuring#

Annotate a function and it becomes a gated benchmark. This page is dogfood. The prose is bound to soothfast's own source, the example below compiles and runs soothfast-measure's production code in CI with its real output spliced in, and the numbers are checked claims evaluated against this build's own measurement run.

From annotation to measurement#

That attribute is the real annotation from soothfast-measure's own bench suite. Every soothfast crate carries one and measures itself this way. cargo soothfast measure runs it under every available backend, and cargo soothfast gate compares against a baseline or merge-base and exits non-zero on a regression.

The statistics underneath#

Every walltime measurement is reduced with summarize, which reports median and median absolute deviation rather than mean and standard deviation. That way a single scheduler blip cannot drag the summary. It sorts in place and never sees NaN, since the samples are durations.

Numbers in prose are gated facts#

✓bench_summarize—allocations 4(limit ≤ 8)0limit 8

Summarizing a sample set costs at most eight allocations.

✓bench_fnv1a—allocations 0(limit ≤ 0)0limit 0

If either sentence stops being true, or the output above stops matching the real one, cargo soothfast docs check fails CI. It is the same mechanism that keeps every page on this site honest.
