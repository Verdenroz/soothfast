# acme-core

JavaScript bindings for the `acme` crate, generated by [soothfast](https://github.com/Verdenroz/soothfast). Do not edit by hand: run `cargo soothfast bind gen` instead.

## Use

```js
import init, { Counter, Level, Mode, digest, normalize, stamp, trim } from "./pkg/acme-core.js";

await init();
```

## Not bound

- acme::Counter::consume: takes `self` by value, which would empty the handle the binding holds; take `&self` and return a new value instead
- acme::with_time: foreign type `chrono::DateTime` has no mapping; add one under [bind.types] in soothfast.toml
- acme::index_all: `HashMap<String, u32>` cannot cross into wasm: wasm-bindgen carries no map type; return a list of pairs, or a struct with named fields
- acme::merge: crosses the exported type `Counter` by value, which would copy it; take it by reference, or add a method returning what the caller needs
